# Nyxframe for iOS

Native SwiftUI companion app for the [Nyxframe](../README.md) FastAPI/React project. Browse and upload photos/videos/GIFs, react and comment, manage your uploads in Studio, follow other creators, and get notifications — all against the same backend the web app uses.

Built the same way as the developer's [Lumisound](https://github.com/HeavenlyXenusVR/Lumisound) iOS app: pure SwiftUI (no React Native/Capacitor), project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`, distributed by sideloading (AltStore/Sideloadly) rather than the App Store.

## Navigation (Nocturne redesign)

The app is organised around a floating dock rather than a tab bar:

| Dock | What's there |
|---|---|
| **Explore** | The feed — tonight's moon phase + greeting, unified search, the Spotlight carousel (trending this week), Echoes (on this day), and a staggered grid under a pinned sort/category shelf |
| **Library** | Collections, liked posts, following feed, trending, categories, plus "recently liked" and "your collections" shelves |
| **＋ Create** | Opens Upload as a sheet over whatever you're looking at |
| **Inbox** | Activity (notifications, split into New / Earlier) and Messages in one place |
| **You** | Identity card, Studio snapshot, friend requests, collections, settings |

Media detail and chat threads hide the dock for an immersive view; it also steps aside for the keyboard. Re-tapping the current dock item returns that stack to its root.

## v1 scope

Included: auth (login/register/2FA/age verification), Discover feed with filters, media detail (like/bookmark/react/comment+reply/similar/report), upload (with AI-analyze toggle and scheduling), Studio (manage your uploads), profiles (follow/friend/block/mute), notifications, and settings (backend URL, theme, 2FA, blocked list, saved searches, data export).

Deferred to a later pass: direct messages/group threads, the owner-only Admin dashboard (use the web app for that), Studio bulk-edit, and dedicated trending/category screens (Discover's filters cover the same queries).

## Dev loop

```sh
brew install xcodegen   # once
cd ios
xcodegen generate
open ImageGallery.xcodeproj
```

Run on a simulator or device from Xcode as usual. First launch will auto-discover the live backend URL from `live-config.json` (same mechanism the web frontend uses); to point at a local backend instead, open Settings → Backend (or the login screen's "Backend settings" link) and enter e.g. `http://127.0.0.1:8788`.

## Building an IPA locally

```sh
./scripts/build-ipa.sh
```

Runs `xcodegen generate`, archives in Release configuration, and exports to `build/export/ImageGallery.ipa` using an auto-generated `ExportOptions.plist` (development signing style) if one doesn't already exist.

## CI

- **`.github/workflows/build-ios.yml`** — runs on every push touching `ios/**`; builds an **unsigned** IPA (`macos-latest` runner) and uploads it as a build artifact, along with the `.xcarchive` for local re-signing.
- **`.github/workflows/release-ios.yml`** — runs on tags matching `ios/v*`; same build, but if the four signing secrets below are set in the repo it exports an **ad-hoc signed** IPA instead of unsigned. Either way it publishes a GitHub Release and updates `ios/altstore-source.json` so AltStore users get automatic updates.

### Signing secrets (optional — unsigned builds work without them)

| Secret | Contents |
|---|---|
| `IOS_CERTIFICATE_BASE64` | `base64 -i YourCert.p12` |
| `IOS_CERTIFICATE_PASSWORD` | password for the `.p12` |
| `IOS_PROVISION_PROFILE_BASE64` | `base64 -i YourProfile.mobileprovision` |
| `IOS_TEAM_ID` | your 10-character Apple Developer Team ID |

## Installing a build

**AltStore (auto-updates):** add this source URL in AltStore → Sources:

```
https://raw.githubusercontent.com/HeavenlyXenusVR/Nyxframe/main/ios/altstore-source.json
```

**Sideloadly / manual:** download the latest `ImageGallery-*.ipa` from [Releases](https://github.com/HeavenlyXenusVR/Nyxframe/releases) and install with [Sideloadly](https://sideloadly.io/) or AltServer.

## Apple TV (tvOS 17+)

`NyxframeTV` is a second target in the same XcodeGen project. It reuses the
iOS app's models, API client, session/auth, image cache, social view models
and `VideoPlayerController`, and adds its own focus-driven interface:

- **Tabs:** Discover (categories, media type, sort, "On this day", endless
  grid, Slideshow, Surprise Me), Trending (time windows + top creators),
  Search (posts and people, popular tags), Library (Following, Liked,
  Collections), Inbox (notifications, messages with replies, friend
  requests) and Account (sign-in with two-factor, music and playback
  settings).
- **Posts:** full-screen images, native AVKit video with a quality menu in
  the transport bar, captions when generated, resume position, likes,
  saves, reactions, threaded comments, Previous/Next through the feed and
  a "More like this" shelf.
- **Background music, 24/7:** starts at launch with no interaction (no
  account needed), shuffles the admin's tracks forever, recovers from
  stalls, dropped connections and audio interruptions on its own, fades
  out when a video starts and fades back in when the video reaches its
  end (or when you leave it). The remote's Play/Pause toggles it while
  browsing; volume, skip and on/off live in Account.
- **Slideshow:** ambient full-screen photo mode that keeps the TV awake.
- **Synced background:** every screen sits on the same rotating gallery
  background the website shows (`/api/site/background`), crossfading over
  5 seconds at the web's 50% strength when the server rotates it.
- **Home filters** include the web's 18+ choice (Show / Hide / Only 18+,
  remembered on the TV), and grids are always four cards across.

Browsing, watching and the music all work signed out; signing in unlocks
the personal feeds, likes, comments, inbox and messaging.

**Build:** `xcodegen generate`, then build the `NyxframeTV` scheme for an
Apple TV or the tvOS Simulator. CI (`.github/workflows/build-tvos.yml`)
produces an unsigned `NyxframeTV-*.ipa` artifact that can be signed and
sideloaded onto an Apple TV.
